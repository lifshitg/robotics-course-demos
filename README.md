# robotics-course-demos

Private TA preparation materials for the Robotics & Autonomous Systems course.
The course has 13 weekly TA sessions, each 45 minutes long. Materials are prepared
one week at a time, beginning with [Week 1 — ROS 2](week01_ros/TEACHING_NOTES.md).

Each prepared week contains:

- `TEACHING_NOTES.md` — private preparation notes, timing, and a teaching checklist.
- `PRESENTATION_PLAN.md` — a slide-by-slide outline for a future presentation.
- `demo/` — code and files for the live demonstration.

Sessions follow three parts: context / recap, core explanation, and live demo.
Only Week 1 is currently set up. Its [ROS 2 live demo](week01_ros/demo/README.md)
includes a simple Python publisher and subscriber.
