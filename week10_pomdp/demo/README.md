# Week 10 — Board work

This theoretical session uses worked examples and short in-class exercises instead
of an executable demo. No installation or software commands are needed.

1. **Example A:** begin with belief `(0.6,0.4)`, apply **move**, and predict `(0.52,0.48)`.
2. Work through the **red** observation: posterior approximately `(0.8298,0.1702)`.
3. Ask students to calculate the **blue alternative from the same prediction**:
   posterior approximately `(0.1193,0.8807)`.
4. **Example B is a new question:** reset belief to `(0.5,0.5)`. Sense leaves the state
   unchanged and costs 1. Compare immediate commitment (value 0) with sensing then
   choosing a commitment from the observation (value 6).
5. Draw the sensing policy tree and show the [immediate-commitment value plot](../visuals/commitment_values.svg).

See the [teaching notes](../TEACHING_NOTES.md) for all model tables, calculations,
answers, and timing, and the [presentation outline](../PRESENTATION_PLAN.md) for
planned reveals. These TA-created examples use the professor's notation; they are
not homework questions. The actual homework solution is reserved for Week 11.
